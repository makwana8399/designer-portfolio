# Portfolio

Personal portfolio site — Next.js + React Three Fiber + GSAP, styled as a
dark "system console" experience (WebGL background, boot sequence, scroll
choreography, settings panel).

- **Plan & status:** see [`PLAN.md`](./PLAN.md)
- **Pending inputs (resume/images/links/etc.):** see [`TODO.md`](./TODO.md)
- **All copy/data:** [`src/content/site.ts`](./src/content/site.ts) — single
  source of truth, edit this file to change any text on the site

## Development

```bash
npm run dev      # start dev server at http://localhost:3000
npm run build    # production build
npm run start    # run the production build locally
```
